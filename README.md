### 🔎 Research Approach

I am most interested in the critical transition from research paper to working implementation, and from implementation to reliable evidence.

I prioritize:
- Independent reproduction of research methods
- From-scratch implementation when official code is unavailable
- Experimental design driven by clear methodological questions
- Careful examination of assumptions, representations, limitations, and failure modes
- Fully reproducible computational pipelines
- Transparent documentation that allows others to inspect and verify the work

I aim to develop as a researcher who can move rigorously from:

**research question → method → implementation → experiment → evidence**
